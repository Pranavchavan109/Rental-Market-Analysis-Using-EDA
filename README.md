# Rental-Market-Analysis-Using-EDA

🏡 Rental Market Analysis Using Exploratory Data Analysis (EDA)
📊 Project Overview

This project focuses on analyzing rental housing data to understand the key factors influencing property prices in the real estate market. Using Exploratory Data Analysis (EDA) techniques, the dataset was cleaned, processed, and visualized to uncover meaningful patterns related to rental trends, furnishing status, property size, and location-based pricing behavior.

The goal of this analysis is to transform raw housing data into actionable insights that help interpret how different attributes affect rental property values.

🎯 Objectives
Understand rental price distribution across properties
Identify relationships between carpet area and price
Analyze the impact of furnishing status on rental values
Explore correlations between numerical housing features
Detect patterns across different housing attributes
Generate insights useful for market understanding and decision-making
🛠️ Tools & Technologies Used: Python, Pandas, NumPy , Matplotlib, Seaborn, Jupyter Notebook

📂 Dataset Description

The dataset includes structured housing-related information such as:

Rental Price
Carpet Area
Furnishing Status
Property Characteristics
Location-based attributes

These variables were analyzed to identify pricing patterns and relationships across different housing features.

🔍 Project Workflow

1️⃣ Data Cleaning
Checked missing values
Removed inconsistencies
Converted data types where required
Prepared dataset for analysis
2️⃣ Univariate Analysis

Explored individual feature distributions using:
Histograms
Count plots
Summary statistics

This helped understand the spread and behavior of rental prices and housing attributes.

3️⃣ Bivariate Analysis

Analyzed relationships between variables such as:

Carpet area vs rental price
Furnishing status vs rental price
Feature comparisons across housing categories

Scatter plots and comparative visualizations were used to interpret trends.

4️⃣ Correlation Analysis

Generated correlation heatmaps to identify relationships between numerical variables and understand feature dependencies influencing rental prices.

📈 Key Insights
Carpet area showed a strong positive relationship with rental price
Furnished properties generally had higher rental values than unfurnished properties
Rental prices varied significantly depending on housing attributes
Correlation analysis revealed moderate relationships between selected numerical features
Data visualization helped identify important pricing behavior patterns within the dataset
📊 Visualizations Included

The analysis includes:

Distribution plots
Scatter plots
Count plots
Correlation heatmap
Feature comparison charts

These visualizations helped interpret pricing structure and rental market characteristics effectively.

🚀 Outcome of the Project

This project demonstrates how Exploratory Data Analysis can be used to:

Clean and prepare real-world datasets 
Identify meaningful feature relationships 
Interpret rental pricing behavior 
Build strong foundations for further predictive modeling or dashboard development
